# Pibes de Barrio

Landing pública del proyecto Pibes de Barrio.

## Acceso rápido

- Página online para abrir desde el celular: https://braianruaimi.github.io/Pibesdebarrio-QR/
- Repositorio GitHub: https://github.com/braianruaimi/Pibesdebarrio-QR
- QR PNG: assets/qr/pibesdebarrio-landing-qr.png
- Afiche A4 PDF: assets/qr/pibesdebarrio-afiche-a4.pdf

## Uso

Abrí la página online desde cualquier navegador del celular o escaneá el QR para entrar directo.

## Instalable

La landing está preparada como app web instalable. Si abrís la página desde el celular, podés instalarla y cuando haya una nueva versión aparecerá el botón para actualizar.
